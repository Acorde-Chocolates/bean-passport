Every batch, sealed from bean to bar.

Acorde Chocolates records each production step of a batch. Bean Passport seals a fingerprint of that record on Solana, so anyone can check it from the QR code on the wrapper, without trusting us.

Three steps

How it works

  1. Record

    The factory's spreadsheet turns each closed production step into a canonical record: dates, weights in grams, origin. Nothing personal or financial. See how a record is built →

  2. Seal

    The official wallet signs a Solana memo carrying the SHA-256 of that record. Each seal covers every earlier step, so a later edit breaks all the seals after it. For producers: seal a step →

  3. Verify

    The batch passport recomputes the hash in your browser from the data it shows and compares it with the memo on Solana. You can also check it in a terminal.

A seal proves the record hasn't changed since it was sealed, and when it was sealed. It doesn't prove the numbers are true: a wrong number typed before sealing stays wrong, and the seal attests it faithfully.
